# 旺财宝 · AI 商家经营助手

根据用户提供的 Figma 文件制作的交互演示，适配手机和桌面浏览器。

## 运行

需要 Node.js 22.13 或更高版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。经营首页可点击渐变提示或“问问旺小财”进入聊天；底部主题可发起趋势、时段、经营对比与建议分析。右上角可以查看和新建对话；桌面左侧提供认证和登录演示入口。

## 演示范围

业务数据、AI 回答、登录、资料识别、认证审核和设备绑定均为模拟。无需 API 密钥。请勿输入真实身份或银行卡信息。对话仅保存在当前页面内存中，刷新会重置。

原稿内部分数字存在不一致，首页保留设计稿显示值，AI 分析使用独立的演示数据。该版本没有连接真实收款和认证服务。
